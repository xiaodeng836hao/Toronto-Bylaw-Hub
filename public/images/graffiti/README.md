# Graffiti page images

The "Know the Difference" module on `/tmc-chapters/485` references two example
images by these EXACT file names. Save the provided images here (PNG):

| File name                    | Image                                            | Shown in card        |
| ---------------------------- | ------------------------------------------------ | -------------------- |
| `graffiti-tags-example.png`  | Black spray-paint tags on a white brick wall     | Graffiti Tags (red)  |
| `mural-example.png`          | Colourful "TORONTO" skyline mural with flowers   | Mural (blue)         |

Both render at a 16:10 crop (object-cover), so any landscape image works.
Paths are defined in `lib/graffiti-485.ts` (`DIFFERENCE_TAGS.image` / `DIFFERENCE_MURAL.image`).
